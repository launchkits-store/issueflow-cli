# ⚡ IssueFlow CLI

> **Zero-config local issue tracker for developers who live in the terminal.**

Manage your dev tasks, sprint items, and bugs directly from your CLI without leaving your code editor or switching context to bloated web dashboards.

## 🔥 Features

- 🚀 **Zero Configuration:** Works out-of-the-box in any local git directory.
- 📁 **SQLite Storage:** Instant local persistence with zero network latency.
- 🏷️ **Tagging & Priorities:** Filter tasks by `#bug`, `#feature`, `#high-priority`.
- ⚡ **Lightning Fast:** Built with Node.js and lightweight SQLite engine.

## 🚀 Quick Start

```bash
npm install -g issueflow-cli
issueflow init
issueflow add "Fix JWT token expiration bug" --tag bug --priority high
issueflow list
